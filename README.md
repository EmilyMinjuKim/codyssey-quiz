# Codyssey Quiz

Python으로 만든 터미널 퀴즈 게임입니다.
터미널, Git, Docker에 관한 기본 문제 5개를 제공하며, 사용자가 문제를 추가할 수 있습니다.

## 실행 방법

Python 3.11 환경에서 개발했습니다. 외부 패키지 설치는 필요하지 않습니다.

프로젝트 폴더에서 실행합니다.

```bash
python3 main.py
```

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| 1. 퀴즈 풀기 | 등록된 문제를 순서대로 출제하고 정답 여부와 결과 표시 |
| 2. 퀴즈 추가 | 질문, 선택지 4개, 정답 번호를 입력받아 문제 등록 |
| 3. 퀴즈 목록 | 등록된 문제 수와 질문 표시 |
| 4. 점수 확인 | 지금까지 가장 많이 맞힌 문제 개수 표시 |
| 5. 종료 | 문제 목록과 최고 점수를 저장하고 종료 |

빈 입력, 숫자가 아닌 입력, 허용 범위를 벗어난 번호는 다시 입력받습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 메뉴, 입력 검증, 게임 진행, JSON 저장·불러오기 |
| `quiz.py` | 문제 출력과 정답 판정을 담당하는 `Quiz` 클래스 |
| `quiz_data.py` | 기본 퀴즈 5개 생성 |
| `state.json` | 실행 중 저장하는 문제 목록과 최고 점수 |
| `README.md` | 프로젝트 소개와 실행·검증 방법 |

`Quiz`는 개별 문제를 표현합니다.
`QuizGame`은 문제 목록과 최고 점수를 관리하고 게임 기능을 호출합니다.

## 데이터 저장과 불러오기

- 시작할 때 `main.py`와 같은 폴더의 `state.json`을 읽습니다.
- 저장 파일이 없으면 기본 문제 5개와 최고 점수 0점으로 시작합니다.
- 메뉴 5번으로 종료하면 현재 문제 목록과 최고 점수를 저장합니다.
- 재실행하면 저장된 문제와 최고 점수를 복원합니다.
- JSON 문법이나 데이터 형식이 잘못되었거나 파일을 읽지 못하면 안내 후 기본값으로 시작합니다.
- 저장에 실패하면 오류 메시지를 표시합니다.

### 주의 사항

- 메뉴 5번, Ctrl+C 또는 입력 스트림 종료(EOF)로 게임을 종료하면 현재까지 등록된 문제와 최고 점수를 저장합니다. 입력 중인 미완성 문제와 완료하지 않은 게임의 점수는 반영하지 않습니다.
- 손상된 저장 파일로 시작한 뒤 메뉴 5번으로 종료하면 기본 데이터로 덮어씁니다. 오류 처리 실습 전에는 저장 파일을 백업해야 합니다.
- 최고 점수는 정답 개수입니다. 문제 수가 달라지면 같은 조건의 점수 비교가 아닐 수 있습니다.

## 기능 확인 방법

1. 메뉴에 빈 입력, 문자, 범위 밖 숫자를 입력하여 재입력 안내를 확인합니다.
2. 퀴즈를 풀며 정답·오답 판정과 최종 정답 개수를 확인합니다.
3. 문제를 추가하고 목록과 퀴즈 풀기에 반영되는지 확인합니다.
4. 높은 점수를 기록한 뒤 낮은 점수를 받아도 최고 점수가 유지되는지 확인합니다.
5. 메뉴 5번으로 종료한 뒤 재실행하여 문제와 최고 점수가 유지되는지 확인합니다.

## Git 활용

- 기능 단위로 변경 내용을 커밋했습니다.

## 데이터 파일 구조

게임 기록은 프로젝트 루트(main.py와 같은 폴더)의
`state.json`에 UTF-8 인코딩으로 저장합니다.

| 필드 | 자료형 | 의미 |
|---|---|---|
| `quizzes` | 배열(list) | 등록된 퀴즈 목록 |
| `question` | 문자열(str) | 문제 내용 |
| `choices` | 배열(list) | 선택지 문자열 4개 |
| `answer` | 정수(int) | 정답 번호(1~4) |
| `best_score` | 정수(int) | 한 게임에서 맞힌 문제 개수의 최고 기록 |

`question`, `choices`, `answer`는 `quizzes` 안의 각 문제에 포함됩니다.

구조 예시이며, 실제 저장 파일에는 전체 문제 목록이 들어갑니다.

```json
{
  "quizzes": [
    {
      "question": "Git에서 변경 내용을 커밋으로 기록하는 명령어는?",
      "choices": ["git add", "git commit", "git push", "git clone"],
      "answer": 2
    }
  ],
  "best_score": 1
}
```

`state.json`은 실행 중 생성되는 파일이므로 Git 관리에서 제외합니다.
저장소를 처음 복제한 환경에서는 기본 문제 5개와 최고 점수 0점으로 시작합니다.
